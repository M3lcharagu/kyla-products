# XAUUSD Scalper Journal

Printable/Notion-ready process for XAUUSD. Educational only; test on demo.

## Rules
- Maximum **3 closed trades per day**, win or lose.
- Define entry, stop, target, invalidation, and risk before entry.
- Stop after the daily loss limit or any rule-breaking; never size up to recover.

## Formulas
- `R multiple = net trade P/L / planned initial risk`; planned loss is `-1R`.
- `Win rate = winning trades / total closed trades`.
- `Profit factor = gross profit / ABS(gross loss)`; if gross loss is zero, report `N/A`.
- `Expectancy R = win rate × average winning R − loss rate × average losing R`.
