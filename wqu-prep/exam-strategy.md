# Exam Strategy — Target 90%+

## Official versus recommended
> **OFFICIAL INFORMATION (confirm current WQU instructions):** **60 questions, 2 hours, one sitting, 75% pass, up to two attempts**.

A 90%+ target, the pacing below, skip thresholds, and error-log method are **recommendations**, not official rules or guarantees. The questions in this pack are original practice, not official questions.

## The 90%+ system
Aim for 54/60 minimum and practice toward 56–58 to create a buffer.

1. **First pass (0:00–0:55):** harvest definitions, direct computations, and familiar patterns. Flag anything without a visible route after about 45 seconds.
2. **Second pass (0:55–1:40):** write the governing formula, estimate sign/scale, calculate, and eliminate options.
3. **Audit (1:40–2:00):** check signs, units, domains, endpoints, dimensions, probability totals, and the exact wording.
4. Change an answer only when a re-read or calculation supplies evidence.

Two hours for 60 questions averages two minutes each. This pacing is a recommendation; bank the point if one item is consuming time needed for easier items.

## Topic playbook
- **Python:** trace types, indexing, mutability, precedence, and loop bounds.
- **Statistics:** identify population/sample, parameter/statistic, center/spread, and requested interpretation.
- **Probability:** define events; distinguish independent from mutually exclusive; use complements for “at least one.”
- **Algebra:** preserve equivalence, factor, track restrictions, and test roots.
- **Linear algebra:** write dimensions before products; use geometry for dot products, rank, and projections.
- **Calculus:** name product/chain/quotient/FTC rules; include endpoints for extrema.
- **Discrete:** translate words into logic, sets, counts, or graphs.
- **Differential equations:** classify order/linearity/separability, use given data, then substitute back.

## Drill loop
Attempt a mixed 30-question set in 60 minutes; log score, confidence, time, and error type; reteach the weakest rule in one sentence; re-solve with changed numbers; raise the target after two consecutive 90%+ attempts.

## Traps
Definitions are not synonyms; negative signs and inequality reversals matter; correlation is not causation; matrices need compatible dimensions; calculus needs constants/domains/endpoints; one hard question must not consume several easy points.
