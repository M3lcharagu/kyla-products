# Advanced Algebra

## THE ONLY THING YOU NEED TO KNOW

- **Structure beats expansion:** Factor first, identify restrictions, and use the form of an expression to choose the shortest valid method.
- **Functions are input-output rules:** Track domain, inverse operations, transformations, and composition rather than treating formulas as disconnected symbols.
- **Equations require equivalence checks:** Every multiplication, division, squaring, or logarithm step can add or remove candidates; record restrictions and check the original equation.
- **Patterns generalize:** Arithmetic and geometric sequences, exponentials, logarithms, and binomial coefficients are compact descriptions of repeated change.

## Worked Example

Solve \(x^2-5x+6=0\). Look for two numbers whose product is \(6\) and whose sum is \(-5\): \(-2\) and \(-3\). Thus \(x^2-5x+6=(x-2)(x-3)\). Set each factor to zero, giving \(x=2\) or \(x=3\). Substitution confirms both values.

## MEMORY TOOLS

- **Mnemonic:** **F-R-E-C** — **F**actor, note **R**estrictions, preserve **E**quivalence, **C**heck.
- **Hooks:** “The denominator is a gate”; “The exponent is a repeated multiplier”; “The vertex is the quadratic’s turning address”; “A log is an exponent question.”
- **Mini mind-map:**
  ```text
  expression
  ├─ factor → zeros / cancellation (with restrictions)
  ├─ exponent ↔ logarithm → growth / inverse growth
  ├─ sequence → arithmetic (add) or geometric (multiply)
  └─ quadratic → roots, axis x = −b/(2a), vertex
  ```
- **When-you-see-X-think-Y:**
  - See \(a^x=b\) → think “rewrite with a common base, then equate exponents.”
  - See \(\log_a u=c\) → think “\(u=a^c\), with \(u>0\).”
  - See a rational expression → think “exclude denominator zeros before simplifying.”
  - See \(|u|=k\) → think “\(u=k\) or \(u=-k\), provided \(k\ge0\).”
  - See a quadratic inequality → think “find roots, test an interval, respect the leading sign.”
- **Common-trap warnings:** Do not cancel across addition; do not distribute an exponent over a sum; reverse an inequality when multiplying or dividing by a negative; do not accept extraneous roots created by squaring; and remember that \(\log(a+b)\ne\log a+\log b\).
