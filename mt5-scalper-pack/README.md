MT5 SCALPER PACK — INSTALL README
1. Download ORB.mq5 and SessionVWAP.mq5.
2. In MT5 choose File > Open Data Folder.
3. Open MQL5 > Indicators.
4. Copy both .mq5 files there.
5. Restart MT5 or refresh Navigator.
6. Open MetaEditor and compile with F7.
7. Attach from Navigator > Indicators.
8. Set session inputs to broker server time.
9. Check the box, levels, line, and label visually.
10. Test on demo before any live trading.
